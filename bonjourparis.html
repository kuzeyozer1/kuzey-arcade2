⛏️ PARIS PACK

A Minecraft Bedrock add-on made for your trip.

What's inside
🥖 Baguette: eat it, or hit mobs with it (7 damage!)
🥐 Croissant · 🍬 Macaron · 🫓 Chocolate Crepe
🗼 A command that builds a giant Eiffel Tower (75 blocks high!)
🏛️ The Arc de Triomphe and a 🎆 fireworks show

Opens the share menu: pick Minecraft (scroll the apps or tap More).

1️⃣BEHAVIOR PACK.mcpack, if the one above won't import 2️⃣TEXTURE PACK.mcpack, import this one too
How to install (iPhone / iPad)
  1. Tap 📲 SEND TO MINECRAFT and choose Minecraft in the share menu (it needs internet the first time).
  2. If your iPad shows strange letters instead, that means it opened the file as text. Close it, open the Files app → Downloads, hold paris-pack.mcaddon → Share → Minecraft.
  3. Minecraft says "Import started" then "Successfully imported".
  4. Create a world → Behavior Packs → activate Paris Pack (the textures turn on by themselves).
  5. Turn Cheats on so the commands work.
Commands (type them in chat)
/function paris/help list of everything
/function paris/eiffel builds the tower in front of you
/function paris/arc Arc de Triomphe
/function paris/kit free Paris snacks
/function paris/fireworks night show 🎆

Recipes (crafting table)
🥖 3 wheat in a diagonal line
🥐 2 wheat + 1 egg
🍬 sugar + egg + pink dye → 4 macarons
🫓 wheat + egg + sugar + cocoa beans

💡 Tip: build the tower in a flat or creative world. Stand where you want it, look forward, then type the command. It appears 24 blocks ahead.

✈️ PLANE TIPS

Before you take off (while you still have internet):

1. Open Kuzey Arcade in Safari, wait 10 seconds, then pull down to reload once. Now every game is saved on your iPhone.

2. Tip: tap Share → Add to Home Screen so the arcade opens like an app.

3. Open each game you want to play one time, just to check it works.

4. Download the Minecraft Paris Pack and import it before the flight.

5. Then switch on Airplane Mode and test: the arcade should still open! ✈️

🔊 The French voice in the phrasebook uses your iPhone's built-in voice, which works offline too. If it stays quiet, check that silent mode is off.
