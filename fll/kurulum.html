FLL Pit Crew: öğretmen kurulumu

Öğrencinizin takım için hazırladığı FLL Pit Crew uygulaması, ödevleri, duyuruları ve robot denemelerini tüm sınıfla paylaşmak için ücretsiz bir Supabase hesabına ihtiyaç duyuyor. Kurulum yaklaşık 10 dakika sürer, kredi kartı gerekmez.

Neden gerekli?

Uygulama şu anda verileri sadece her cihazın kendisinde tutuyor. Supabase, sınıfın verilerini güvenli bir şekilde çevrimiçi saklar. Ödev ve duyuruları yalnızca sizin hesabınız ekleyebilir; bu kuralları veritabanının kendisi uygular.

  1. Ücretsiz hesap açın

    supabase.com adresine gidin ve e-posta adresinizle (veya GitHub hesabınızla) kaydolun. E-postanıza gelen onay bağlantısına tıklayın.

  2. Yeni bir proje oluşturun

    • New project düğmesine tıklayın. Plan olarak Free seçili kalsın.
    • Name: FLL Pit Crew
    • Database password: Generate a password ile bir şifre oluşturun ve güvenli bir yere kaydedin. Bu şifreyi kimseyle paylaşmayın; uygulama için gerekmez.
    • Region: Türkiye'ye en yakın olan Central EU (Frankfurt).
    • Create new project düğmesine tıklayın ve projenin hazırlanması için 1–2 dakika bekleyin.

  3. Öğrenci cihazlarının e-postasız girişini açın

    Öğrenciler ve takım bilgisayarı e-posta kullanmadan, sadece grup koduyla katılır.

    • Soldaki menüden Authentication → Sign In / Providers sayfasını açın.
    • Allow anonymous sign-ins seçeneğini açın ve Save changes ile kaydedin.

  4. Uygulamanın adresini girin

    Böylece e-posta onay bağlantıları doğrudan uygulamayı açar.

    • Authentication → URL Configuration sayfasını açın.
    • Site URL alanına şunu yazın ve kaydedin:
    https://kuzeyozer1.github.io/kuzey-arcade2/fll/

  5. Veritabanı kurulumunu çalıştırın

    • Soldaki menüden SQL Editor sayfasını açın ve New query deyin.
    • Aşağıdaki kodun tamamını kopyalayıp yapıştırın ve Run düğmesine tıklayın.
    • Sonuçta Success. No rows returned yazısını görmelisiniz. Uyarı (notice) çıkarsa sorun değil.
    Bu kod yalnızca FLL Pit Crew'un kendi tablolarını ve güvenlik kurallarını oluşturur. Tekrar çalıştırmak zararsızdır.
    Yükleniyor…

  6. İki bilgiyi öğrencinize gönderin

    • Sayfanın üstündeki Connect düğmesine tıklayın veya Project Settings → API Keys sayfasını açın.
    • Project URL: https://xxxxxxxx.supabase.co şeklinde bir adres.
    • Publishable key: sb_publishable_ ile başlayan anahtar (eski projelerde anon public adlı, eyJ ile başlayan anahtar).
    Bu iki bilgi zaten herkese açık olacak şekilde tasarlanmıştır; uygulamanın içine yerleştirilecekler. Güvenliği, 5. adımda kurulan kurallar sağlar.
    Asla paylaşmayın: veritabanı şifresi ve sb_secret_ ile başlayan gizli anahtar (eski adıyla service_role).
Sonrasında
  • Öğrenciniz bu iki bilgiyi uygulamaya ekletecek. Ardından uygulamada Öğretmen olarak giriş ile e-postanız ve bir şifreyle hesabınızı oluşturup grubu başlatacaksınız.
  • Ücretsiz projeler 7 gün hiç kullanılmazsa duraklatılır. Böyle olursa Supabase panelinde projeye girip Restore project demeniz yeterlidir; veriler kaybolmaz.
  • Sınıf verileri bu projede, sizin hesabınızda durur. İstediğiniz zaman projeyi silerek tüm verileri kaldırabilirsiniz.

FLL Pit Crew: teacher setup

Your student built the FLL Pit Crew app for your team. To share homework, announcements and robot runs with the whole class, it needs a free Supabase account. Setup takes about 10 minutes, and no credit card is needed.

Why is this needed?

Right now the app only keeps data on each device. Supabase stores the class's data safely online. Only your account can post homework and announcements, and the database itself enforces that rule.

  1. Create a free account

    Go to supabase.com and sign up with your email (or a GitHub account). Click the confirmation link in your email.

  2. Create a new project

    • Click New project. Keep the Free plan.
    • Name: FLL Pit Crew
    • Database password: click Generate a password and save it somewhere safe. Don't share it with anyone; the app doesn't need it.
    • Region: Central EU (Frankfurt), the closest to Turkey.
    • Click Create new project and wait 1–2 minutes while it's prepared.

  3. Let student devices join without email

    Students and the team computer join with just the group code, without an email address.

    • In the left menu open Authentication → Sign In / Providers.
    • Turn on Allow anonymous sign-ins and click Save changes.

  4. Enter the app's address

    This makes email confirmation links open the app.

    • Open Authentication → URL Configuration.
    • Set Site URL to this and save:
    https://kuzeyozer1.github.io/kuzey-arcade2/fll/

  5. Run the database setup

    • In the left menu open SQL Editor and click New query.
    • Copy all of the code below, paste it in, and click Run.
    • You should see Success. No rows returned. Notices are fine.
    It only creates FLL Pit Crew's own tables and security rules. Running it again is harmless.
    Loading…

  6. Send two things to your student

    • Click the Connect button at the top of the page, or open Project Settings → API Keys.
    • Project URL: an address like https://xxxxxxxx.supabase.co.
    • Publishable key: the key starting with sb_publishable_ (in older projects, the anon public key starting with eyJ).
    These two are designed to be public; they'll be built into the app. The rules from step 5 are what keep the data safe.
    Never share: the database password, or the secret key starting with sb_secret_ (called service_role in older projects).
Afterwards
  • Your student will have these two added to the app. Then, in the app, you'll use Sign in as teacher to create your account with your email and a password, and start the group.
  • Free projects pause after 7 days without any use. If that happens, open the project in Supabase and click Restore project; no data is lost.
  • The class's data lives in this project, in your account. You can remove all of it at any time by deleting the project.
